# 统一全屏设置页面排版与架构规划

## 需求

### 目标

将 Playback 模组现有分散的设置、偏好和可配置内容统一到一个全屏设置页面中。页面从回放浏览器、编辑器及其他可用入口打开时，都进入同一套设置页面，不再分别维护录制设置弹窗、编辑器局部设置弹窗和未来新增的独立设置窗口。

页面必须满足：

- 以全屏 ImGui 页面呈现，覆盖当前游戏窗口的整个可用区域。
- 使用半透明深黑背景，背景下仍可隐约看到当前游戏或编辑器画面。
- 内容区域、导航、按钮、输入框和分组样式与现有 Playback/EditorTheme 统一。
- 设置内容按模块分区，左侧导航切换分类，右侧显示当前分类内容。
- 任何入口打开后都使用相同页面、相同状态、相同保存和退出规则。
- 录制、回放浏览器、编辑器、导出和通用设置都能在同一页面内扩展。
- 不破坏当前 D3D11/D3D12 的游戏画面，只在已有 ImGui UI 渲染链路中叠加半透明页面和控件。

### 设置范围

统一页面覆盖以下设置域：

1. **录制**
   - 开始/结束录制快捷键。
   - 暂停/继续录制快捷键。
   - 录制状态层开关。
   - 状态层位置。
   - 当前录制控制：开始、暂停、继续、结束。
2. **回放浏览器**
   - 默认视图模式。
   - 默认筛选条件。
   - 默认排序字段。
   - 默认排序方向。
   - 自动刷新策略。
   - 缩略图开关和尺寸策略。
3. **编辑器**
   - 恢复默认布局。
   - 详情面板宽度比例。
   - 时间轴高度比例。
   - 轨道列表宽度比例。
   - 默认时间轴缩放。
   - 编辑器快捷键入口和快捷键帮助。
4. **导出**
   - 默认格式。
   - 默认编码器。
   - 默认分辨率。
   - 默认帧率。
   - 默认码率。
   - 默认输出目录。
   - 默认文件名模板。
5. **通用**
   - 语言选择或语言字段的明确处理。
   - 配置恢复默认。
   - 配置文件状态和保存错误反馈。

本规划只定义页面排版、模块边界、状态流转和接入方式；导出后端本身仍属于独立功能，不因页面统一而自动视为已实现。

### 页面打开规则

统一页面使用一个 `SettingsPageState` 管理打开状态和当前分类：

- 从回放浏览器设置菜单进入：打开统一设置页面，默认选中“录制”。
- 从编辑器菜单进入：打开统一设置页面，默认选中“编辑器”。
- 从其他入口进入：根据入口传递的初始分类打开；未指定时默认“录制”。
- 页面打开后隐藏回放浏览器、编辑器菜单和旧的录制设置弹窗，避免两个设置层同时绘制。
- `Escape` 或页面左上角返回按钮关闭页面；未保存草稿时弹出统一确认。
- 页面不会改变当前录制状态、回放播放状态或编辑器工作区，除非用户明确点击当前录制控制按钮或保存设置。

## 架构

### 总体布局

页面采用“全屏深黑遮罩 + 左侧分类导航 + 右侧内容区 + 底部操作栏”的固定结构，不使用居中卡片或嵌套设置卡片：

```text
┌──────────────────────────────────────────────────────────────┐
│ 半透明深黑全屏遮罩                                           │
│   Playback 设置                                      ×      │
│   ├──────────────┬───────────────────────────────────────┤   │
│   │ 分类导航      │ 当前分类内容                          │   │
│   │              │                                       │   │
│   │ ● 录制        │ 标题                                  │   │
│   │ ○ 回放浏览器  │ 描述                                  │   │
│   │ ○ 编辑器      │ ┌─────────────────────────────────┐ │   │
│   │ ○ 导出        │ │ 设置分组                         │ │   │
│   │ ○ 通用        │ │ 标签          控件              │ │   │
│   │              │ │ 标签          控件              │ │   │
│   │              │ └─────────────────────────────────┘ │   │
│   │              │                                       │   │
│   ├──────────────┴───────────────────────────────────────┤   │
│   │ 状态提示                                  取消  保存 │   │
│   └──────────────────────────────────────────────────────┘   │
└──────────────────────────────────────────────────────────────┘
```

### 全屏层

- 使用无装饰、不可移动、不可缩放、禁用 ImGui ini 保存的根窗口。
- 根窗口位置为 `(0, 0)`，尺寸为 `io.DisplaySize`。
- 根窗口背景固定使用深黑 `rgba(0, 0, 0, 204)`，透明度为 `0.8`。
- 页面不绘制居中卡片、面板卡片、卡片边框、卡片填充或渐变；导航、内容和底栏直接位于全屏根窗口内。
- 设置页面所有文字、按钮、标签、说明和错误提示统一使用 16px 字号。
- 根页面打开时，底层游戏画面或编辑器画面保持渲染，不执行额外清屏，不切换 D3D11/D3D12 back buffer 的绘制语义。
- 页面本身是唯一设置容器；录制状态层在设置页面打开时隐藏，避免状态层穿透或与设置内容叠加。

### 全屏内容布局

- 页面使用安全边距直接铺满整个窗口；顶部为标题栏，左侧为固定导航，右侧为自适应内容区，底部为固定操作栏。
- 页面不使用居中内容面板；Child 仅用于布局和滚动，不绘制边框或独立背景。
- 内容区使用 Child 作为独立滚动区域；导航区不随右侧内容滚动。
- 底部操作栏显示保存状态/错误消息，以及“取消”和“保存设置”。

### 左侧分类导航

导航使用纵向列表，不使用多层嵌套菜单：

```text
录制
回放浏览器
编辑器
导出
通用
```

每个导航项包含：

- Lucide 图标。
- 分类名称。
- 当前分类的选中背景。
- Hover 和按下状态。
- 可选的未保存标记或错误标记。

导航样式复用现有 `EditorTheme` 和浏览器导航按钮的颜色、间距、圆角和图标字体。点击分类只切换草稿视图，不立即保存；分类切换不应清空其他分类的草稿。

### 右侧内容排版规范

所有分类遵循相同的信息层级：

1. 页面标题。
2. 一行简短说明，解释该分类影响的范围。
3. 一个或多个设置分组。
4. 每个设置项使用“左标签/说明 + 右控件”的两列布局。
5. 高风险或立即生效的操作放入独立操作分组，并使用警示色或二次确认。

设置项排版规则：

- 标签列固定宽度，控件列靠右对齐或占满剩余宽度。
- 说明文字使用 `textDim`，不与主标签抢夺视觉层级。
- 设置项之间使用现有 `itemSpacing`，分组之间使用更大的垂直间距。
- 复选框、Combo、键位按钮、数字输入框和操作按钮统一使用现有控件风格。
- 不在设置项内部创建独立浮动窗口；键位捕获、错误提示和预览都嵌入当前内容区。
- 长内容只在右侧 Child 内滚动，页面标题、导航和底部操作栏保持固定。

## 执行

### 模块拆分

新增统一设置模块，避免继续把页面逻辑堆入 `SelectReplayScreen`：

| 模块 | 文件建议 | 职责 |
| --- | --- | --- |
| 设置状态 | `editor/settings/SettingsPageState.h/.cpp` | 页面是否打开、来源、当前分类、草稿、脏状态、错误和关闭确认 |
| 设置容器 | `editor/settings/SettingsPage.h/.cpp` | 绘制全屏遮罩、居中面板、标题栏、导航、内容区和底栏 |
| 设置模型 | `editor/settings/SettingsModel.h/.cpp` | 汇总录制、浏览器、编辑器、导出、通用配置的读取/校验/保存 |
| 分类渲染 | `editor/settings/sections/*.cpp` | 每个分类只负责排版控件和更新对应草稿，不直接写文件 |
| 主题组件 | `editor/settings/SettingsWidgets.h/.cpp` | 统一标签行、分组标题、键位按钮、错误提示、预览和操作按钮 |
| 页面入口 | `EditorActionType`、`EditorController` | 统一打开、关闭和指定初始分类的动作流 |

### 数据与保存策略

页面打开时创建一份完整草稿：

```text
持久化配置/运行态偏好
        ↓ load
SettingsDraft
        ↓ 分类切换、控件编辑
SettingsDraft
        ↓ validate
SettingsDraft
        ↓ 保存
配置域写入
```

保存策略：

- 录制配置写入 `mods/playback/config.json` 的 `recordingControls`。
- 回放浏览器默认值写入同一配置文件的 `browser` 节点；当前搜索和选中项不写入。
- 编辑器布局继续写入 `mods/playback/editor-layout.json`。
- 导出默认值写入 `config.json` 的 `export` 节点；导出后端未实现时仍可保存规划值，但页面必须显示“当前不可用”。
- 保存采用一次性校验；任何分类存在错误时阻止整体保存，并将导航错误标记定位到对应分类。
- 保存成功后更新运行时服务；取消时丢弃全部草稿，不改变运行时配置。
- 页面关闭前若存在未保存修改，显示统一确认弹窗：保存并退出、放弃修改、取消关闭。

### 页面入口迁移

1. 新增 `OpenSettings`、`CloseSettings`、`SetSettingsSection` 等统一动作或等价状态接口。
2. 将回放浏览器设置菜单中的“录制设置”改为打开统一页面并传入 `Recording` 初始分类。
3. 在编辑器 `Window` 或 `File` 菜单增加“Playback 设置”，传入 `Editor` 初始分类。
4. 后续主菜单、游戏内快捷入口和其他页面全部复用同一 `OpenSettings`，不新增第二个设置窗口。
5. 旧 `RecordingSettingsPanel` 的草稿、校验和即时录制控制逻辑迁移到新页面的录制分类；迁移完成后删除旧浮动窗口调用和 `mRecordingSettingsOpen` 字段。

### 渲染接入

1. 在 `ImGuiRenderer::render()` 中，将统一设置页可见状态纳入 `uiActive`。
2. D3D11 和 D3D12 均在已有 ImGui NewFrame/RenderDrawData 之间绘制页面。
3. 页面打开时保留底层游戏/编辑器画面，不执行录制状态层路径的清屏逻辑。
4. 页面根窗口绘制半透明背景，底层内容保持可见；不得新增 back buffer 清除或复制流程。
5. 在页面关闭或渲染器不可用时恢复原有浏览器/编辑器绘制路径。
6. 严格配对所有 `PushStyleColor`、`PushStyleVar`、字体缩放和 Child/Window Begin/End，避免污染同帧其他 UI。

### 主题与排版实施

1. 将 `EditorTheme` 中已有颜色、圆角、间距和字体缩放作为唯一基础来源。
2. 抽取回放浏览器导航按钮、面板标题、属性行和底部操作栏中的通用样式，供设置页面复用。
3. 设置页面只定义布局尺寸和模块语义，不复制颜色常量。
4. 使用 Lucide 图标字体，图标尺寸、文本间距和 Tooltip 行为与现有页面一致。
5. 以 `io.DisplaySize` 和现有 `calculateReplayUILayout()` 为基础处理缩放；禁止同时叠加浏览器和编辑器的额外字体缩放。
6. 在宽屏、常规窗口和小窗口下分别限制面板最小宽高；内容溢出时只滚动右侧内容区。

补齐并统一以下 key：

- `playback.settings.title`
- `playback.settings.sections.recording`
- `playback.settings.sections.browser`
- `playback.settings.sections.editor`
- `playback.settings.sections.export`
- `playback.settings.sections.general`
- `playback.settings.actions.save`
- `playback.settings.actions.cancel`
- `playback.settings.actions.restoreDefaults`
- `playback.settings.actions.discardChanges`
- `playback.settings.unsavedChanges`
- `playback.settings.unavailable`
- 各分类字段、说明、错误和确认文案。

同时清理以下硬编码文本：

- 回放浏览器菜单中的“录制设置”。
- 录制设置中的恢复默认、取消、保存设置。
- 设置页面新增的所有标题、按钮、状态和错误信息。

资源包主菜单 `.lang` 和 C++ ImGui JSON 继续按职责分离，但 key 命名保持同一语言风格，并在构建或检查脚本中验证中英文 key 对齐。

### 验证标准

#### 布局

- 从回放浏览器打开时进入统一全屏页面，并默认选中录制分类。
- 从编辑器打开时进入同一页面，并默认选中编辑器分类。
- 页面覆盖完整窗口，背景为半透明深黑，底层画面可见。
- 页面风格与现有回放浏览器和编辑器一致，无突兀的新颜色、字体或控件样式。
- 导航、内容滚动、底部操作栏在不同窗口尺寸下不重叠、不越界。

#### 行为

- 分类切换不丢失草稿。
- 保存成功后对应配置域立即生效并在重启后恢复。
- 取消或放弃修改不改变任何配置域。
- 未保存关闭会统一确认。
- 任意分类校验失败时阻止保存并定位错误。
- 录制控制按钮仍直接操作 `Recorder`，不复制状态机。
- 页面打开期间录制状态层不与全屏设置页面叠加。

#### 渲染

- D3D11 游戏画面不会因页面打开变黑。
- D3D12 游戏画面不会因页面打开变黑。
- 半透明背景只由 ImGui 页面绘制，不新增 back buffer 清屏。
- 页面关闭后回放浏览器、编辑器和录制状态层恢复原有行为。

#### 国际化

- 中文和英文页面所有标题、标签、按钮、错误和状态均来自语言 key。
- 中英文 key 数量和结构一致。
- 不出现硬编码中文残留。

#### 构建与回归

- 执行 `xmake build -y`。
- 检查配置 JSON 能正常读写和恢复默认。
- 检查编辑器布局 JSON 未被统一设置页破坏。
- 检查现有回放打开、编辑、录制快捷键和状态层功能不回归。

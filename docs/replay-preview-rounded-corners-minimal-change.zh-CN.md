# 回放预览圆角最小修改方案

## 需求

- 为 `SelectReplayScreen::drawPreview` 增加圆角参数。
- 使用 ImDrawList 的圆角绘制能力，让概况模式预览图片四角真正裁剪为圆角。
- 概况卡片调用预览时使用 8px 圆角，详细模式列表项调用时使用 3px 圆角，详细面板预览保持 3px 圆角。
- 删除详细模式列表项整项卡片背景填充和外层卡片边框，仅保留交互、文本、缩略图及缩略图边框。
- 不改变既有动画、选择、布局、双击打开和业务逻辑。

## 架构

`SelectReplayScreen::draw` 继续统一驱动回放浏览器 UI；概况模式经 `drawGrid` 调用 `drawCard`，详细模式经 `drawDetails` 调用 `drawDetailsListItem`。两者均通过 `drawPreview` 获取缩略图纹理并提交到当前 ImDrawList。

圆角仅属于预览绘制职责：`drawPreview` 接收调用方指定的半径，使用 `AddImageRounded` 绘制纹理，并用同半径绘制不可用预览背景。列表项的选择动画状态仍继续更新，但不再绘制整项背景或外层边框。

## 执行

1. 更新头文件中的 `drawPreview` 声明，增加圆角参数。
2. 更新实现中的预览背景、纹理和不可用文本占位绘制，统一使用调用方圆角。
3. 更新概况卡片、详细列表项和详细面板预览的调用半径。
4. 删除详细列表项新增的整项背景填充及外层边框绘制，保留缩略图边框。
5. 执行 `git diff --check` 和 Playback Release 构建，确认无格式错误且编译通过。

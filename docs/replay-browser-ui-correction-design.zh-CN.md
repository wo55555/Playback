# 回复菜单 UI 修正设计

## 需求

- 移除详细模式列表项中新增的卡片式背景、外框和圆角包裹。
- 保留详细模式原有列表内容、缩略图、点击选择和右键菜单行为。
- 修复概况模式缩略图四角为直角的问题，使图片本身按卡片缩略图圆角显示。
- 不改变卡片尺寸、布局间距、选中态颜色、动画、回放数据和业务动作。

## 架构

- 修改范围限定在 `SelectReplayScreen` 的绘制层。
- `drawDetailsListItem` 保留列表项交互和文本布局，移除列表项容器的额外背景/边框视觉绘制。
- `drawPreview` 增加圆角参数，由调用方指定缩略图圆角；概况卡片传入卡片圆角，详细列表传入缩略图边框圆角。
- 缩略图使用带圆角的绘制路径裁剪，确保纹理内容和背景同时遵循圆角，而不是只给背景添加圆角。
- 不修改 `ReplayBrowserState`、`EditorController`、扫描逻辑或渲染后端入口。

## 执行

1. 调整 `drawPreview` 接口并实现圆角缩略图绘制。
2. 在概况模式调用处传入 `8.0f` 圆角。
3. 在详细模式调用处传入 `3.0f` 圆角。
4. 删除详细列表项的新增卡片背景和外框绘制，同时保留缩略图边框。
5. 执行 `git diff --check`。
6. 编译 Playback Release 目标，确认没有引入 C++ 或 ImGui API 错误。

## 验收

- 详细模式不再出现额外的卡片包裹背景、外框或圆角。
- 概况模式缩略图四角可见圆角裁剪，图片不会覆盖圆角区域。
- 选择、双击、右键菜单、视图切换及既有动画行为保持正常。

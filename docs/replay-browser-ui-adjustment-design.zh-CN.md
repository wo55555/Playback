# 回复菜单 UI 调整设计

## 需求

### 目标

调整 Playback 回放浏览器的概况模式和详细模式，使选中反馈使用中性灰色，移除蓝色视觉强调，并为按钮、卡片状态和视图切换增加 0.2 秒平滑动画。

### 功能要求

- 所有相关 UI 过渡使用 0.2 秒动画，包含淡入淡出、按钮切换、卡片 hover/选中状态和概况/详细视图切换。
- 概况模式选中卡片从深灰色变为中性灰色，不使用偏蓝色背景。
- 概况模式选中卡片不绘制蓝色描边。
- 概况模式选中卡片移除左上角勾选框。
- 详细信息按钮使用 `ICON_INFO`，不再使用 `ICON_MORE`。
- 详细模式选中列表项使用中性灰色背景，不使用偏蓝色背景。
- 详细模式选中列表项不绘制蓝色描边。
- 不改变回放扫描、选择、多选、双击打开、业务动作和数据模型。

### 验收标准

- 在概况模式单击卡片时，背景在 0.2 秒内平滑变为中性灰色，且没有勾选框和蓝色描边。
- 在详细模式单击列表项时，背景在 0.2 秒内平滑变为同一中性灰色，且没有蓝色描边。
- 卡片右上角显示信息图标，悬停仍可显示文件详情 tooltip。
- 概况与详细模式切换时内容不瞬间闪现，视图在 0.2 秒内完成淡入淡出。
- DX11 和 DX12 渲染路径均继续调用同一回放浏览器绘制逻辑。

## 架构

### 模块关系

`ReplayBrowserState` 继续作为回放数据和业务状态来源，`EditorController` 继续处理刷新、打开和文件操作动作。UI 调整集中在 `SelectReplayScreen`，不向数据层增加表现层字段。

```text
ReplayBrowserState
    -> SelectReplayScreen::draw
        -> drawNavigation
        -> drawGrid -> drawCard
        -> drawDetails -> drawDetailsListItem
```

### 状态边界

- `mViewMode` 仍然保存当前视图模式。
- `mSelectedIds` 仍然保存选中回放，不改变多选和范围选择逻辑。
- 新增的动画状态仅属于 `SelectReplayScreen`，用于保存当前显示进度、目标视图和过渡方向。
- 动画通过 `ImGui::GetIO().DeltaTime` 推进，避免依赖业务时间或系统时钟。

### 视觉状态

- 非选中卡片继续使用现有深色背景。
- 选中卡片和选中列表项统一过渡到中性灰色 `RGB(70, 72, 76)`。
- 选中边框不使用 `kColorAccent`，改为中性灰色边框；也不增加新的蓝色颜色变量。
- hover 状态保持现有中性灰色边框和按钮背景逻辑，并参与 0.2 秒插值。
- 信息按钮绘制使用 `ICON_INFO`，tooltip 链路保持不变。

### 动画边界

- 卡片和列表项使用颜色插值，不改变布局尺寸，避免列表重排造成跳动。
- 视图切换使用旧视图淡出、新视图淡入；切换过程中保留原有业务数据和选择状态。
- 动画到达终点后固定为目标值，避免浮点误差导致持续重绘状态漂移。
- 不新增定时器、线程、持久化字段或外部依赖。

## 执行

### 修改步骤

1. 在 `SelectReplayScreen` 增加统一的 0.2 秒动画常量和帧间进度更新方法。
2. 为视图切换增加目标模式和淡入淡出进度，在导航按钮切换时启动动画。
3. 将概况卡片选中背景、hover 背景和边框改为中性灰色插值，移除选中勾选徽标。
4. 将详细模式列表项选中背景和边框改为中性灰色插值。
5. 将 `drawCard` 中的信息按钮图标替换为 `ICON_INFO`。
6. 编译 Playback 目标，检查 C++ 类型、ImGui API 和警告。
7. 通过回放浏览器手工验证概况模式、详细模式、选中态、tooltip、视图切换以及 DX11/DX12 路径。

### 风险与处理

- ImGui 每帧立即模式绘制无法直接对两个布局做传统页面动画，因此采用同一绘制入口下的透明度过渡，避免引入复杂布局插值。
- 若 `DeltaTime` 出现异常大值，进度仍限制在 `[0, 1]`，确保切换不会卡在中间状态。
- 视图切换期间仍使用当前数据快照，快照刷新逻辑保持原有行为。

### 验证范围

- 静态检查：颜色、图标、勾选徽标和蓝色边框引用均符合需求。
- 构建检查：Playback 目标编译通过。
- 交互检查：卡片单选、多选、双击、tooltip、视图切换和空白取消选择不回归。
- 渲染检查：DX11 和 DX12 均能正常显示动画后的回放浏览器。

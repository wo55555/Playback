# 编辑器摄像机与时间轴交互调整设计

## 需求

- 删除时间轴顶部工具栏中的添加摄像机按钮。
- 将时间轴左侧蓝色添加入口改为 `+` 按钮，并提供可扩展的二级菜单。
- 二级菜单当前包含“添加摄像机序列”和“添加摄像机”；已有摄像机序列时隐藏“添加摄像机序列”。
- 删除原有独立的添加摄像机序列按钮。
- 删除播放工具栏中的速度减按钮、速度加按钮和当前速度文字。
- 时间轴右侧的轨道元素可被选中，选中状态使用更亮的颜色。
- 选中态只提升元素自身的填充色和边框亮度，不使用蓝色覆盖层覆盖轨道元素。
- 时间轴画布支持横向滚轮滚动，轨道列表支持垂直滚轮滚动，Shift+滚轮继续缩放。
- 选中的摄像机序列段继续在详情面板单独设置摄像机绑定。

## 架构

- UI 入口集中在 `TimelinePanel`，只负责绘制控件、判断点击和提交 `EditorAction`。
- 摄像机和摄像机序列的创建继续使用 `AddFreeCamera` 与 `AddCameraSequence`，由控制器和编辑命令层修改项目状态，保留撤销/重做链路。
- 时间轴选择继续使用 `SelectionModel` 的 `SelectedSequence`、`SelectedSequenceSegment`、`SelectedCamera` 和 `SelectedKeyframe`。
- 序列段绑定继续由 `DetailsPanel` 根据 `SelectedSequenceSegment` 显示摄像机下拉菜单，并提交 `BindSequenceCamera`。
- 右侧轨道元素的点击优先消费当前鼠标事件，避免选中轨道或序列段后误触发时间轴空白区域的 Seek。
- `TimelinePanel` 自己维护水平和垂直视图偏移，避免依赖禁用默认滚动的 ImGui 子窗口。

## 执行

1. 在 `TimelinePanel` 工具栏移除添加摄像机入口。
2. 将左侧蓝色添加入口改为 `+`，通过 ImGui popup 菜单承载二级菜单；根据 `project->sequence.empty()` 决定是否绘制添加摄像机序列菜单项。
3. 删除左侧独立的摄像机序列切换按钮。
4. 删除 transport 区域的速度按钮、速度文字和依赖它们的宽度计算，保留播放、暂停、逐帧和首尾跳转。
5. 调整序列段和摄像机轨道自身颜色，当前元素使用更亮的填充色和边框，不绘制覆盖蓝色背景。
6. 增加时间轴轨道列表垂直偏移，并让横向滚轮仅在有横向溢出时移动，解决默认缩放下滚轮被钳制的问题。
7. 保留现有序列段选择与详情面板绑定流程，不在 UI 绘制层直接修改 `cameraId`。
8. 通过静态搜索确认旧入口和速度控件已移除，并执行项目构建验证。
